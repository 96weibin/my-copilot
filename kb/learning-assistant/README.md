# Learning Assistant KB

这个目录是 `Learning Assistant` 的默认知识库目录。

## 软归属说明

这里的 KB 与 agent **没有硬绑定归属**。任何知道这些文件路径的 agent 都可以访问它们；这里是通过“**目录约定 + agent 指令**”形成对 `Learning Assistant` 的默认软归属。

## memory 与 KB 的分工

- **memory**：记录相对稳定的事实，例如长期目标、固定时间预算、学习偏好、长期薄弱点。
- **KB**：记录显式状态，例如当前阶段、本周计划、每日进度、复盘、卡点、路线调整、下一步动作。

## 使用原则

1. 只要这里的 KB 文件存在，就优先把它们当作显式事实来源。
2. 不要只依赖 memory 来维持学习系统状态。
3. 日常学习进度、复盘、卡点、下一步应优先写入这里的 KB 文件。
4. 做学习规划、复盘、路线调整时，要保持多个文件之间的一致性。

## 目录文件

- `learner-profile.md`：学习者长期画像与约束
- `learning-roadmap.md`：阶段路线图与主题推进状态
- `weekly-plan.md`：本周计划与今日优先级
- `review-log.md`：学习复盘日志（新记录追加在顶部）
- `knowledge-gaps.md`：薄弱点与处理动作跟踪
